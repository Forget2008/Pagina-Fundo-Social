# Portal do Fundo Social de Solidariedade

Protótipo institucional desenvolvido para demonstrar uma possível estrutura digital para o **Fundo Social de Solidariedade de Pindamonhangaba**.

## Objetivo

Centralizar informações sobre:

- Cursos gratuitos
- Projetos sociais
- Locais de atendimento
- Informações de contato

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Estrutura

```
index.html
style.css
script.js
README.md
LICENSE
.gitignore
```

## Como executar

Abra o arquivo:

```
index.html
```

no navegador.
