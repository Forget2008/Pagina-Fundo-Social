# 🌍 Portal do Fundo Social de Solidariedade

Protótipo de portal institucional desenvolvido para demonstrar uma possível estrutura digital para o **Fundo Social de Solidariedade de Pindamonhangaba**.

O objetivo do projeto é centralizar informações sobre cursos gratuitos, projetos sociais, locais de atendimento e formas de participação da comunidade.

---

## 🎯 Objetivo

Criar uma demonstração funcional de como um portal dedicado ao Fundo Social pode:

- Facilitar o acesso da população a cursos gratuitos
- Divulgar projetos sociais da cidade
- Informar locais de atendimento
- Melhorar a comunicação com a comunidade

Este projeto foi desenvolvido como **proposta de interface e experiência do usuário**.

---

## 🖥️ Demonstração

O site apresenta as seguintes seções:

- **Página inicial**
- **Indicadores de impacto social**
- **Cursos gratuitos**
- **Projetos sociais**
- **Mapa com locais de atendimento**
- **Informações de contato**

## 🚀 Como executar o projeto

1. Clone o repositório:


git clone https://github.com/seuusuario/fundo-social-site.git


2. Entre na pasta do projeto:


cd fundo-social-site


3. Abra o arquivo:


index.html


no navegador.

Não é necessário instalar dependências.
